How it works

Cross-examine. Re-price. Decide.

Each agent is the same AI with a different job. The script passes work between them; they never talk to each other directly.

01 · Parallel

Cross-examine

Four critics read the pitch, filings and call notes at the same time, blind to each other, so no one anchors on the first opinion.

Why trust it

Built so the AI can't fool you.

Language models are confident and sometimes wrong. Every design choice in Quorum assumes that.

Blind critics

The four critics run in parallel and never see each other's answers, so you get independent views instead of an echo.

Code does the math

The AI picks assumptions. Code computes every price.

price = EPS × P/EE[p] = Σ price × prob

A human signs off

Errors can travel down a chain of agents. Quorum flags disagreements and open questions so a person makes the final call.
